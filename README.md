# Bound

> "can't sleep? neither can we." 
>
> — Mad Routine

Bound is a skill-based, 2D puzzle-action game based off the genre of custom maps in Starcraft: Brood War. The player must navigate a character through a series of deadly traps, timed obstacles, and moving enemies. The game involves precise movement, timing, and planning in order to win.

Bound is a completely free, open source game built from scratch using SDL2 and C#.

## Features (work in progress)

* Story Mode (not started)
* Map Editor (started)
* Skirmish (started)

## Story Mode

Play as "The Runner" as you navigate through various environments, putting up flyers to advertise the band Mad Routine. The more flyers you put up, the more rep you gain. The more rep, the closer you get to meeting the homies Vanessa and Cole.

Along the way you'll meet other fans, collect cards, and gain skillz to improve your run.
